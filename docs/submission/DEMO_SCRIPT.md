# Two-minute demo script

Target runtime: **1:52–1:57**. The official rules state that content after 2:00 will not be viewed, so do not use the final three seconds as planned content.

## Before recording

- Run the app from the fork and open a clean browser window.
- Use a 1440 × 900 or similar desktop viewport at 100% zoom.
- Sign in with the server-verified judge account and begin on the completed starting profile.
- Confirm the console is clean and the generative lesson stamp honestly shows either AI-personalized or reviewed fallback.
- Practice the lesson-stage clicks and one answer before recording.
- Record only the app window. Do not show API keys, terminals, DevTools, local data files, or browser bookmarks.

## Script and actions

### 0:00–0:08 — The problem

**Say:** “Most ACT tools give every student the same calendar. Generic chatbots can explain a problem, but they do not know what the student has actually proved.”

**Show:** Scout onboarding. Keep the three-input premise visible.

### 0:08–0:22 — Required baseline and skill map

**Say:** “Every learner takes the same full 66-question starting diagnostic. It measures all 12 question types before lessons unlock.”

**Show:** The completed Round 0 result and the four diagnostic-based skill polygons.

### 0:22–0:42 — Tour the real dashboard

**Say:** “Mr. Kim now tours the actual dashboard. Each step scrolls to the real control, darkens the rest of the page, and puts the current action in the visual center.”

**Show:** The spotlight moving through Lessons, My Week, Full Diagnostic, Timed Practice, Progress, Badges, Mr. Kim, and Settings.

### 0:42–1:10 — Segmented learning path

**Say:** “The first round teaches every question type in 12 short, schedulable lessons. Later 12-lesson rounds keep the same size but put the weakest measured skills first.”

**Show:** The timeline, one lesson’s Method and Need to know stages, and the five-question check.

### 1:10–1:38 — Correct every miss

**Say:** “A weak lesson check does not produce busywork or a fake completion. Mr. Kim explains each miss, then the learner answers that question correctly before the next lesson unlocks.”

**Show:** The remediation explanation, retry, and newly unlocked next lesson.

### 1:38–1:57 — Repeat the evidence cycle

**Say:** “After the round, the learner chooses another diagnostic or a full test, corrects every missed question with Mr. Kim, and gets the next focused round. The language model explains; code still owns answers, scores, and gates.”

**Show:** The assessment choice and the next-round transition.

## Recording rules

- Never say the model predicts an official ACT score. It predicts skill readiness and next-answer probability.
- Never imply the representative judge profile is a real student.
- If the live LLM is not configured, show the reviewed fallback stamp and keep the narration honest.
- Prefer one clean cut over rushing or exceeding two minutes.
- Add captions. Keep music quiet enough that every technical claim is clear.
