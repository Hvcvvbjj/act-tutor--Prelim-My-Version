# Bundled fonts

AlexACT bundles the Latin subsets of Geist, Geist Mono, and Archivo so
production builds do not depend on a Google Fonts request.

- Geist and Geist Mono: SIL Open Font License 1.1
- Archivo: SIL Open Font License 1.1

The font files are the same subsets previously produced by Next.js for the
project's `next/font/google` configuration.
